# 化学试卷索引入表

把知识库侧新增的化学试卷/答案/补充资料写入六列索引表，并生成当日 dated 交付物。具体知识库 id、队友 id、网盘连接名、绝对路径放记忆/例程，不要写进本技能。**禁止**把索引上传或覆盖进 ima 知识库——写回始终由用户本人做。**硬约束**：只改索引 csv/xlsx（及技能约定的同名工作副本/测试镜像同步），不动核对树以外任何文件。

## When to use

- 高三试卷知识库Bot（或同等交接）priority 通知：某知识库「只增」了试卷/答案/补充资料，列出 title、路径、media_id、卷答线索，并声明未写索引进知识库。
- 用户直接要求：把刚入库的文件补进索引 / 更新今日索引交付物。
- **不要**用于：周六全量对账（例程；第二技能未建）、电子教材、双向细目表、用户自行写回知识库索引。

## Steps

1. **确认交接清单**：解析新增文件列表；按卷答线索合并成「套」或「单文件补充资料」；记下知识库侧相对存储路径（不是本机核对副本路径）。
2. **取可打开副本**：若共享核对目录尚无文件，向知识库Bot 索取复制到约定核对树（保持相对路径）；拿到后再继续。
3. **打开内容核对**（强制）：逐个打开 PDF/Word 等，确认学科为化学、卷/答角色、是否卷答合一、是否可入表；扫描无文字层则渲染首页/关键页。记录与文件名不一致的正文标题。
4. **加载最新基线索引**：以最新「知识库试卷索引_日期」csv 为基线（同目录工作副本可同步）；列必须是：试卷名称｜试卷类型｜试卷文件｜答案文件｜存储路径｜备注。
5. **判已有 / 新增**：
   - 已有：同存储路径下试卷文件名或答案文件名已在表中 → 不重复加行（可更新备注若用户要求）。
   - 新增：配对卷+答合成 **一行**；仅卷/仅答则另一列「—」并在名称加（仅试卷）/（仅答案）；卷答合一则答案列「—」、名称加（卷答合一）。
6. **填字段**：
   - 试卷名称：优先正文标题的可读短名；可与既有系列命名对齐。
   - 试卷类型：套卷 / 高考真题 / 专题练习 / 日常练习 / 其他（用本 bot 默认能力判定；勿默认转 DeepSeek）。
   - 试卷文件 / 答案文件：知识库内文件名原文。
   - 存储路径：知识库相对路径；卷答同路径只写一条；不同路径才同格并列（少见）。
   - 备注：文件名与正文不一致、内容同源但路径不同、补充资料说明、缺文件等。
7. **入表规则过滤**：电子教材跳过；双向细目表跳过；补充资料入表（类型常用专题练习/其他，备注标明补充资料）。
8. **自检**：新行列齐全、类型合法、无同名套卷误重、打开抽查新行引用文件仍对得上；总行数=基线+净增行。
9. **写出交付**：生成「知识库试卷索引_YYYY-MM-DD」（用户时区当天）；同步同目录工作副本名（如 `revised-v2`）与测试镜像目录；上传/覆盖用户网盘根目录同名 csv+xlsx（或用户指定网盘位置）。
10. **成功确认**：向用户汇报新增行摘要、总行数、交付链接/路径；FYI 知识库Bot「已入表、未写回知识库」。基线旧日期文件可保留不删。

## Naming / columns

- 交付名：`知识库试卷索引_YYYY-MM-DD`（csv + xlsx）。
- 固定六列：试卷名称｜试卷类型｜试卷文件｜答案文件｜存储路径｜备注；缺省占位符「—」。
- 名称标签：（卷答合一）（仅试卷）（仅答案）。
- 工作区：共享索引目录 + 测试镜像目录 + 内容核对树（相对路径镜像知识库目录结构）。
- live 清单 / media_id：用于核对线索，**不必**写入索引表列。

## Stop conditions

- 交接清单为空或全是电子教材/细目表等排除项 → 不改表，说明原因。
- 无法取得可打开副本且无法内容核对 → 停手，向用户或知识库Bot 要文件，不凭文件名瞎写。
- 内容核出非化学/损坏/无法配对且用户规则不允许猜测 → 该条不入或仅备注待定，先汇报。
- 用户要求暂停 → 立即停。
- 只允许改索引 csv/xlsx（及步骤 9 约定的工作副本/测试镜像同步）；触及核对树以外任何文件 → 立即停。

## Keep out of this skill

索引写回 ima（始终由用户本人做）；是否删除某行、合并内容同源多路径行、补入历史零散文件、改列结构等需用户当场拍板的事；具体 KB id、Bot id、密钥、某次日期基线文件名、OneDrive item id；模型路由（本 bot 默认能力；点名 DeepSeek 另遵记忆）；周六全量对账的 cron 与叫醒文案（属例程；第二技能未建）。
