# 阅卷复查工作流

考后在**在线阅卷平台**上做复查。正式生产环境：**默认只复查**，不改系统分、不提交，除非用户当场明确许可。具体站点 URL、账号、vault id、当次考试内容放记忆，不要写进本技能。

## When to use

用户考后通知开始改卷/复查，或点名「阅卷复查」时启用。

## Steps

0. **先问平台（硬规则）**：开场必须先问「本次用的是哪个阅卷平台？」；**不默认任何平台**。未得到平台答复前，不登录、不截卷、不评分。

   **怎么问（选项卡，像 A/B/C/D）**：用聊天选项卡（widget），不要只用纯文字列表。选项按字母编号：
   - 已知平台各占一档，标签形如 `A. 云阅卷`（可附简短网址说明；具体 URL 来自记忆，可写在选项 value 或随后确认里）。
   - **最后一档永远是**「其他（我填网址）」——允许用户自填完整网址（`allowCustom` 或等价自定义输入）。
   - 记忆里只有一个已知平台时 → 两档：`A. …` + `B. 其他（我填网址）`；以后多了就变成 A/B/C…，末项仍是「其他」。
   - 用户选了已知平台 → 用记忆中的 URL 继续；选了「其他」→ 等用户给出网址后再登录。

1. **登录**：平台确定后，再用 Vault 登录（或用户提供的账密），按 `sign-in` / `vault` 流程登录。具体账号与 URL 写在记忆，不写死在技能。

2. **截卷约定（通用）**：进入复查/已阅列表，按页截取答卷图落盘；定位用「第N页第M张」（或该平台等价定位）；文件命名建议 `{平台短码}-p{页两位}-s{张两位}.jpg`，工作目录按当次任务自建（如 `/workspace/<任务短名>/`）。视口可见张数可能少于每页总数，必须滚完再翻页。

3. **只复查**：对照**标准答案**与用户提供的**原始截图/答卷图**，查漏给分与给分是否合理。日常用本 Bot 默认模型 + 本机工具；**仅用户明确要求**才 SendToAgent DeepSeek Bot（id `10e0081a-6f55-4ef9-a865-b5b77f44316a`）。**不用 Gemini**，也不走 Composio DeepSeek。未经许可不改系统分、不提交、不点「保存/提交」类按钮。

4. **评分细则快查**（始终适用；用户可当次补充）：
   - 方程式类型与题目要求不符（要化学方程式却写离子方程式，或反之）→ 该空 **0 分**；
   - 物质都对但未配平 → 该空 **扣 1 分**；
   - 其他细则以当次用户补充为准，记入记忆并当次执行。

5. **争议表**：交付 CSV（或等价表），字段约定：定位（第N页第M张 / `page`·`slot`）、`system_score`、`suggested_score`、可选 `delta`、双方理由（`reason_system` / `reason_suggested`，或合并为 `reason`）。产物名建议 `disputes-all.csv`。

6. **题目分析工作报告**：**直接发给用户，不经 Grok Bot**；风格参照完整复查简报但更细——逐空错因、高频错答并附**典型例子**、争议给分理由展开。产物可为 `briefing` /「题目分析工作报告」（扩展名按交付形态）。

## Stop conditions

- 用户未答复「本次用哪个阅卷平台」（含未选选项、未填「其他」网址）；
- 无法登录，或缺标准答案/截图且用户未补；
- 用户未授权却需要改分、提交或任何写操作；
- 用户说停、取消、先别动；
- 环境异常（站点不可用、验证码无法过等）→ 报告现状并停，不绕过。

## Keep out of this skill

某次考试题号、标准答案正文、某次争议份数；具体 URL、账号、vault id、某次工作目录文件清单；「默认云阅卷」「默认叫 DeepSeek」；改分/提交的自动授权。已知平台清单可增长，但**清单本身放记忆**，技能只规定「选项卡 + 末项其他」的问法。
