- schedule: CRON_TZ=Asia/Shanghai 0 23 * * 0
- timing: exact
- enabled: true

## Prompt
每周日晚收集四 bot 周报的催交回合（Asia/Shanghai）。三个业务 bot 每周固定向你交工作周报；DeepSeek Bot 每周交模型与余额周报。你只在每月 1 日与 15 日再汇总给用户，本回合不要做半月报、也不要主动给用户发周报摘要。

向以下四位 Grok Bot 队友各发一条 priority 为 true 的站立催交，请他们用简体中文写本周周报，并用 SendToAgent 发回给你（Grok Bot）：

三位业务 bot（学科网试卷Bot、高三试卷知识库Bot、知识库索引Bot）写清三块——本周做了什么、遇到的困难、现有工作流可改进之处。

DeepSeek Bot 单独交「模型周报」，写清两块即可：本周实际调用了哪些模型；当前账户余额（DeepSeek 官方余额与百炼/阿里云现金）。不要查、也不要写调用次数或 token 等用量细账。查不到的余额如实写「未查到」，不要编造。

在持久存储记下本周周报窗口的开始时间、「等待中」状态，以及 DeepSeek 报来的余额快照（若有），便于半月汇总时对比上期与本期。不要代他们写周报正文。

结果交给：本聊天里的用户。若四位都催到了，本聊天保持安静；若某 bot 不可达，用一两句说明谁没催到，不要静默。
